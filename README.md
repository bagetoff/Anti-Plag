Изменена логика сравнения токенов, а именно вместо сопоставления токенных слов, теперь сравниваются символы: 
 - ```N = <NUMBER>``` &nbsp;&nbsp;&nbsp;цифры, числа используемые в коде (в комментариях не учитывается)
 - ```S = <STRING>``` &nbsp;&nbsp;&nbsp;все строки и т.п. (вида 'text')
 - ```C = <CHAR>  ``` &nbsp;&nbsp;&nbsp;означает константу одиночного символа, заключённую в одинарные кавычки в коде
 - ```I = <IDENT> ``` &nbsp;&nbsp;&nbsp;любое пользовательское имя (переменные, названия функций и т.п.)
